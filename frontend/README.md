# Frontend

## Mobile Stack
- React Native
- Redux Toolkit
- React Navigation

## Setup Instructions
1. Install dependencies using `npm install`
2. Run the app using `npm start`

## Folder Structure
- `src/store`: Contains Redux store and slices.
- `src/navigation`: Contains navigation setup.
- `src/screens`: Contains all screens.
- `src/db`: Database setup.

## Nativewind Setup
- Follow the Nativewind [installation guide](https://www.nativewind.dev/docs/getting-started) for setup instructions.
