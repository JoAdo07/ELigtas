How it works

Three steps. No feed to scroll.

ELigtas is built around a simple idea: saving a video should make it easier to find later, not harder.

01

Paste a link

Drop in a public YouTube, TikTok, or Instagram URL. We keep the canonical link and fetch public metadata where the platform allows it.

02

Let it sort

If an OpenAI-compatible key is configured, the AI picks a category. Without one, a deterministic keyword scorer keeps things working offline.

03

Make it yours

Override a category, search across titles and creators, and export the whole library as JSON. Nothing leaves your browser unless you send it.

The honest scope

What about my whole saved folder?

Bulk imports of your liked or saved videos need OAuth and platform API approval from TikTok or Instagram. This build supports link-by-link import so it works today, without pretending to have access it doesn't.
